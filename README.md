awesome-selfhosted 1.0.0
Visit the improved version of the Awesome-Selfhosted list at https://awesome-selfhosted.net/

Awesome-Selfhosted is a list of Free Software network services and web applications which can be hosted on your own server(s). Self-hosting is the practice of hosting and managing applications on your own server(s) instead of consuming from SaaSS providers.

The website at awesome-selfhosted.net is now the recommended way to browse the list. It features improved search, categorization, layout, more detailed information, and should generally provide a better browsing experience. The old, familiar markdown version of the list will keep receiving automated updates for the foreseeable future.

You are encouraged to use, modify, improve and redistribute the list under the terms of the Creative Commons Attribution-ShareAlike 3.0 license. Raw data, tools used to build markdown and HTML versions, issues and pull requests are now available under the awesome-selfhosted-data repository. You can find information on how to contribute to the project here.

Thanks to more than 1200 contributors for keeping this project going since 2015.
